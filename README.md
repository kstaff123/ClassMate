# 📚 ClassMate

**A Western Washington University Course Planning and Browsing System**  
Built with **React, Strapi, and PostgreSQL**

---

**Entirely Student Built**  
Aiming to replace the outdated classfinder system, ClassMate offers a modern, intuitive way for WWU students to browse and plan their courses.

---

## Overview

ClassMate is designed by students, for students. With a sleek UI built in React, a robust back-end powered by Strapi, and PostgreSQL handling our data, we've created a platform that simplifies the course selection process at WWU.

---

## Features

- **Modern, Responsive UI:** Built with React for a smooth user experience.
- **Efficient Course Browsing:** Quickly search and filter courses.
- **Interactive Course Planning:** Easily build your quarter schedule.
- **Student-Centric Design:** Developed by fellow students who understand the need for support on multiple devices.
- **Up-to-Date Replacement:** Modern solution to overhaul the legacy classfinder system.

---
## Get Started
- Install project dependencies
- Set up frontend and backend .env files
- Start frontend with `npm run dev`
- Start backend with `npm run develop`
---

## Built With

- **[React](https://reactjs.org/):** For building the user interface.
- **[Strapi](https://strapi.io/):** To manage our back-end and APIs.
- **[PostgreSQL](https://www.postgresql.org/):** For data storage and management.
